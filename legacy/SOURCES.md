# Sources

## Canonical original

- **File**: `creative_computing/aceyducey.bas`
- **Title**: ACEY DUCEY CARD GAME
- **Author**: Bill Palmby, Prairie View, Illinois
- **Publication**: *BASIC Computer Games* (David H. Ahl, ed.),
  Creative Computing Press, Morristown, New Jersey, 1973 (revised 1978).
  Also distributed in DEC's *101 BASIC Computer Games*.
- **Language**: Dartmouth-style line-numbered BASIC (Microsoft-compatible).
- **URL retrieved**: `https://raw.githubusercontent.com/GReaperEx/bcg/master/aceyducey.bas`
  (mirror of the Ahl listing; identical to the well-known Creative Computing original).
- **Status**: Code listings from *BASIC Computer Games* were published for
  type-in use without any restrictive license; widely considered public
  domain / de-facto abandonware. The clean reference text used here matches
  the original printed listing.
- **Selected as canonical**: yes. This is the primordial Acey-Ducey source
  and the most-ported BASIC game in history alongside *Hunt the Wumpus*.

## Notes on alternative versions

A search for ZX Spectrum, Amstrad CPC, MSX or C64 type-in variants did not
surface any meaningfully different listing of *Acey-Ducey* in the time
budget; ports to those platforms reproduce the Ahl logic with at most
cosmetic substitutions (e.g. `CLS` vs. `HOME`, screen-edge `INK` codes).
The 1978 Creative Computing listing is therefore the sole reference and no
[LICENCIA CREATIVA] substitution was needed.
